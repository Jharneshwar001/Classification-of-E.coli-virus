This project applies machine learning for DNA sequencing-based E. Coli detection using MLPClassifier, achieving 93% accuracy. Built with Python, Pandas, NumPy, Scikit-learn, Seaborn, and Matplotlib, it processes genomic data from the UCI Molecular Biology dataset. The models are evaluated using F1-score and precision, ensuring accurate bacterial identification. This work contributes to bioinformatics, medical diagnostics, and microbiology research.
